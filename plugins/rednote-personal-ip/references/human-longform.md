# 高人感长文：正文与标题

只在用户明确要写人物故事、职场经历、品牌观点、项目复盘、影评 / 书评、PLOG、关系记录、社群活动、阶段性随笔或长篇个人感悟时读取。普通干货、单个标题或短文案不要加载这份参考。

目标不是把每篇写成散文，而是让读者看见：**为什么偏偏是这个人，会得到这个判断。** 不复制其他创作者的原句、口头禅或经历。

## 一、先找叙事引擎，不新增问卷

从用户已有材料里内部选择一个引擎；只有材料不足时，最多问 2–3 个高价值问题，不把选择题丢给用户。

| 叙事引擎 | 适合 | 先找什么材料 |
|---|---|---|
| 人物 / 事件镜像 | 榜样、演出、电影、他人故事触发的自我理解 | 对方的一个具体行为；它如何照见作者身份变化 |
| 小行动证明价值 | 文化身份、关系、成长、公共议题 | 作者的犹豫；后来做了什么；收到了什么回应 |
| 身份对比 | 海外生活、回国、转行、成为父母、毕业 | 两种生活 / 角色的具体差异与双方代价 |
| 项目决策 | 品牌、创业、工作复盘 | 一个真实决定、限制条件、结果或未解决问题 |
| 阶段模型 | 学生、职业、长期成长 | 一套贯穿全文的比喻；每阶段一个真实情境 |
| 微小动作 | 离别、成长、日常随笔 | 一个物件、动作或删除 / 保留的痕迹 |

长文优先补齐以下 5 项中的 3 项：身份坐标、触发瞬间、内在拉扯、实际选择、后续回声。没有这些材料，不靠抽象感悟、名人引语或祝福句填满。

## 二、标题：人感与网感

标题至少组合 **身份 / 场景 / 动作 / 未完成结果** 中的两项；承诺的内容必须在正文前 200 字得到兑现。

| 适用场景 | 标题结构 |
|---|---|
| 人物认可 / 反转 | `<我以为的关系>，后来<具体结果>` |
| 身份 + 触发 | `在<身份 / 时间>，我因为<一件事>做了<动作>` |
| 微小动作 + 变化 | `当我<具体动作>，我才发现<变化>` |
| 有限立场的建议 | `<问题>？我这个<相关身份>反而不敢轻易劝你` |
| 个人清单 | `<数字>件对我有用、但没写进 To-do list 的事` |
| 阶段性观点 | `<具体阶段>是一场<作者能用正文证明的判断>` |

避免：只有大词的标题（成长、勇气、体验、松弛）、“独家秘籍”却没有操作、夸张诊断、攻击他人、未核实的事件或身份背书。

## 三、六种正文骨架

### 1. 人物 / 事件镜像

```text
触发：我为什么会注意到这个人 / 事件
证据：1–2 个可确认的行为、场景或短引文
转折：它如何改变我对自己、身份或选择的理解
落点：回到自己的一个具体行动、愿望或未解问题
```

写的是作者的变化，不是人物履历。影视、历史、明星与文化内容只使用用户提供或可核对的事实；不编剧情、轶事、数据或长引文。

### 2. 项目 / 品牌复盘

```text
原先以为：过去的理解或方案
碰到什么：一个具体决策 / 卡点
怎么取舍：预算、材料、渠道、用户、执行或协同限制
结果与后续：什么被验证；什么仍要改善
```

品牌理念必须在一个真实决定中成立。产品、核心人群、渠道、复购、内容支柱或组织取舍至少落到一项；不要只写“我更热爱品牌了”。

### 3. 有限立场的建议 / 阶段模型

```text
问题：谁在问、为什么现在问
立场：作者的身份、利益关系和经验边界
分层：不同阶段 / 目标 / 性格下的差别
判断：给取舍维度，不替读者做唯一决定
收尾：回到一项真实代价或下一步
```

只用一套核心比喻，并让每个阶段都有一个具体观察。个人经验不能包装成普遍规律。

### 4. PLOG、关系与微小动作

```text
具体场景 / 物件 / 动作
连续的 3–5 个生活切片或共同记忆
其中一个轻微不完美、犹豫或吐槽
回到一个具体愿望、主题词或余味
```

时间、地点、人物、物件、动作至少有三个真实锚点。不要用“很幸福 / 很感动 / 很有力量”替代关系证据，也不强行升华。

### 5. 影评、书评与文化评论

```text
观看 / 阅读前后的一个真实感受
一个可核对的角色行动、场景或文本线索
我从中读到的关系、选择或时代问题
回到一个意象、动作或仍未说尽的余味
```

只写用户确认的内容；短引文优先，未核实的引语不用。不要把作品评论写成泛泛人生哲理。

### 6. 清单、冲突与生活化软植入

**个人清单**：每项至少包含“具体做法 + 为什么对我有用 / 何时不适用”；不把 20 条人生箴言堆在一起。

**职场冲突**：背景与时间压力 → 原定流程 → 关键分歧 → 可确认后果 → 我的判断或真问题。去掉可识别同事信息、攻击性标签与族群 / 国籍化描述。

**生活化软植入**：生活场景 → 选择标准 → 已确认的产品功能 / 使用感 → 回到生活主题。不得虚构参数、体验、合作关系或效果；商业合作按平台要求标识。

## 四、网感不等于碎句和堆梗

- 前 100–200 字说清“发生了什么、为何值得讲”，不把背景拖到最后。
- 可保留自然口语、轻微自嘲、括号、短停顿或 emoji，但只在声音档案允许时使用。
- 段落按完整逻辑单元分；短句只给钩子、转折、原话或真正的余味。
- 允许作者承认幼稚、害怕、没想明白或改观；不要从头到尾像全知导师。
- 结尾可以停在画面、动作、未解矛盾或一个真问题，不需要每篇都喊口号。

## 五、抽象感悟与敏感话题拦截

离开、成长、体验、松弛、勇气、内耗等抽象主题，至少先补两个：实际动作、关系变化、具体物件 / 场景 / 身体感受、不体面的念头、尚未解决的矛盾。否则只给结构稿或“供确认”的候选，不写成可发布长文。

心理健康内容必须区分个人感受、咨询中的个体解释与普遍医学结论；不自行诊断、不承诺疗愈效果。引用、数据、文化与历史事实必须由用户提供、可核对，或明确标为个人感受。
