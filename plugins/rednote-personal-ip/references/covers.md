# 小红书封面：款式、渲染、AI 生图

封面承担了小红书 80% 的点击决策。用户在信息流里看到的封面只有约 **200px 宽**，所以判断一张封面好不好，唯一的标准是：**缩小到指甲盖大小，主标题还能不能一眼读完。**

## 规格

| 项 | 值 | 说明 |
|---|---|---|
| 比例 | 3:4 | 小红书首页占位最大的比例，优先用这个 |
| 像素 | 1242 × 1656 | 模板已按此设定；平台另一个常见规格是 1:1 的 1080×1080 |
| 单张体积 | ≤ 10MB | 2x 出图后如超了，降 quality 而不是降分辨率 |
| 张数 | 单条笔记最多 **9 张** | 轮播型排版就是按这个上限设计的 |
| 安全区 | 四周 90px，底部 150px | 底部会被平台 UI 和标题文字压住 |
| 主标题字号 | ≥ 96px | 低于这个数缩略图就糊了 |
| 主标题字数 | ≤ 12 字 | 超过就要拆两行，或者删字 |
| 一屏信息 | ≤ 3 个 | 主标题 + 副标 + 一个身份标识，再多就是噪音 |

## 长图轮播（图2-图9）

轮播型笔记是把整篇内容做成图，正文只留几句引导。**收藏率最高的形态** —— 用户收藏的是一整套能随时翻出来看的东西，而不是一段文字。

`covers.html` 里有三款内页模板：

| class | 页型 | 用在哪 |
|---|---|---|
| `style-page-point` | **分点页** | 主力页型，一页讲一个点 |
| `style-page-quote` | **金句页** | 过渡和强调，一整页只放一句话 |
| `style-page-end` | **结尾页** | 收尾 + 互动引导 + 账号信息 |

### 排版顺序

6-9 页最合适。少于 6 页撑不起"值得收藏"的观感，超过 9 页发不出去（平台上限）。

```
图1  封面        ← 6 款封面里选，只负责让人点进来
图2  痛点/背景   ← 分点页，先说"你是不是也这样"，建立共鸣再给方法
图3  第 1 点     ← 分点页
图4  第 2 点     ← 分点页
图5  金句        ← 金句页，中间换一次呼吸节奏
图6  第 3 点     ← 分点页
图7  结尾页      ← 总结三条 + 互动问句
```

**图2 不要直接进方法。** 用户刚点进来，需要先确认"这篇是写给我的"，第二页就上干货会掉一批人。

**金句页别省。** 连着五页都是分点页，看到第三页就腻了。中间插一页只有一句话的，节奏立刻不一样 —— 这是轮播型看起来专业不专业的分水岭。

### 内页的字号逻辑

内页比封面小一档：封面是缩略图里抢点击，字必须夸张；内页是点进来后全屏读的，可以承载更多信息。

- 内页小标题 76-82px，正文 46-52px
- 每页正文控制在 100 字以内，塞满了就是没删干净
- 一页只讲一个点。想讲两个，就拆成两页

### 页码和账号名

每一页都带页码（`2/8`）和一个账号标识。页码让人知道还剩多少，愿意划完；账号名是被截图转发时唯一的归属标记 —— 轮播图被单张转发是常事，没署名等于白做。

## 6 种款式怎么选

模板位于插件根目录的 `assets/covers.html`，改 `<body>` 的 class 切换。

| class | 款式 | 适合 | 气质 |
|---|---|---|---|
| `style-poster` | **大字报** | 干货、观点、反常识 | 冲击力最强，缩略图辨识度第一 |
| `style-memo` | **便签手账** | 学生、日常、经历分享 | 亲和、真实、有温度 |
| `style-checklist` | **清单目录** | 教程、合集、"收藏就够" | 信息密度高，收藏率最高 |
| `style-quote` | **语录** | 情感、心理、感悟 | 留白多，气质最好，但点击率吃标题 |
| `style-contrast` | **对比** | 避坑、纠错、before/after | 天然引发自我检验，点击稳 |
| `style-photocard` | **照片+文字卡** | 生活、穿搭、探店、旅行 | 需要有好照片撑，否则廉价 |

### 按 IP 类型的默认推荐

- **情感博主** → 语录 为主，大字报 为辅
- **知识干货** → 大字报 + 清单目录 交替
- **专业专家** → 大字报（低饱和配色）+ 对比
- **经历分享** → 便签手账 + 照片文字卡

**首次给用户做封面时，把 6 种都渲染出来让他挑一种当固定款式**，然后写进 IP 档案。个人 IP 的视觉统一比单张好看重要得多 —— 用户刷到第三条时要能认出这是同一个人。

## 风格主题：让封面不像"模板"

**版式 ≠ 风格。** 上面 6 款只是信息怎么排；决定这张图像不像小红书批量模板的，是配色、字体、纹理和装饰 —— 也就是风格。

`covers.html` 里有 7 套风格主题，和版式解耦，**两个 class 叠加使用**：

```html
<body class="style-poster theme-editorial">
```

9 种版式 × 7 套风格 = 63 种组合，但每套风格内部视觉语言是统一的。

| class | 主题 | 气质 | 适合 |
|---|---|---|---|
| *(不写)* | 原生米白 | 米白+珊瑚红，安全牌 | 通用，但辨识度最低 |
| `theme-editorial` | **杂志感** | 象牙白、衬线大字、黑色横线、零圆角 | 专业专家、观点类 |
| `theme-retro` | **胶片复古** | 芥末黄+砖红、颗粒噪点、双层描边 | 经历记录、生活类 |
| `theme-mono` | **极简黑白** | 只有黑白、超大字重、零装饰 | 观点、反常识、态度类 |
| `theme-aura` | **弥散光** | 多层渐变、毛玻璃、大圆角 | 情感、心理、疗愈类 |
| `theme-doodle` | **涂鸦手账** | 奶油底、虚线框、荧光笔、圆润字形 | 学生、日常、经历分享 |
| `theme-ink` | **水墨清雅** | 宣纸色、衬线体、朱红印章 | 心理、文化、人文类 |
| `theme-pop` | **撞色 pop** | 撞色块、粗描边、硬阴影 | 观点、玩梗、态度类 |

### 怎么帮用户选

**渲染同一个版式的多个主题，让用户看图选**，不要用文字描述让他想象 —— 风格这件事说不清楚，看一眼就知道。

选定后写进 IP 档案，之后固定用这一套。想做变化就换版式，不要换主题 —— **主题是账号的脸，版式只是这条笔记的骨架。**

按 IP 类型的起手推荐：情感/心理 → `theme-aura` 或 `theme-ink`；知识干货 → `theme-editorial` 或 `theme-mono`；学生/经历分享 → `theme-doodle` 或 `theme-retro`；想最大化辨识度 → `theme-mono` 或 `theme-pop`。

### 微调配色

主题只是起点。改 `covers.html` 顶部 `:root`（或某个 `body.theme-*` 块）里的变量就能调，不要改别的地方。

- 点缀色只用在**一个**地方（高亮块或强调字），全用了就没有重点
- 大字报款式的主色会铺满整屏，饱和度太高会显得像广告，取中低饱和
- 专业类账号（心理/医疗/法律）避开大红大黄，用低饱和的蓝绿灰更可信

### 字体

模板默认用系统里一定有的思源黑体 / 思源宋体，所以在任何环境都不会掉字。想再拉开一档辨识度，装一个个性更强的中文字体，然后改 `--font-sans`：

```bash
apt-get install -y fonts-lxgw-wenkai   # 霞鹜文楷，文艺/手账风最好用
```

装不上（比如网络受限）也不影响出图，会自动回落到思源黑体 —— 字体链里写好了 fallback。

## 渲染成 PNG

改完 `covers.html` 后跑下面这段。写成脚本文件或直接 `python3 -c` 都行。

```python
from playwright.sync_api import sync_playwright
from pathlib import Path

HTML  = Path("<plugin-root>/assets/covers.html").resolve()          # 替换为实际插件根目录
STYLE = "style-poster"                          # 要渲染的款式
OUT   = "cover.png"

with sync_playwright() as p:
    b = p.chromium.launch()
    # deviceScaleFactor=2 出 2x 高清图，小红书压缩后仍清晰
    pg = b.new_page(viewport={"width":1242,"height":1656}, device_scale_factor=2)
    pg.goto(HTML.as_uri())
    pg.evaluate(f"document.body.className = '{STYLE}'")
    pg.wait_for_timeout(400)          # 等字体加载完，漏了这步中文会掉成方框
    pg.screenshot(path=OUT)
    b.close()
```

几个容易踩的点：

- **`wait_for_timeout` 不能省**。字体没加载完就截图，中文会渲染成方框或回退字体，排版全乱。
- **`device_scale_factor=2`** 出的是 2484×3312，小红书上传会压缩，2x 图压完才够清晰。
- 环境里要有中文字体（Noto Sans CJK / 思源黑体）。缺字体时先装：`apt-get install -y fonts-noto-cjk`。
- 批量出图时循环改 `className` 再截图即可，不用重开浏览器。

渲染完**一定要自己看一眼图**（Read 工具可以直接读 PNG），确认没有文字溢出、没有方框、缩略图下标题可读。字太多溢出容器时，优先删字而不是缩小字号。

### 批量出轮播

轮播型要出 6-9 张，每页内容不同。做法是准备一份页面数据，循环写入 DOM 再截图，不要手改 HTML 改九遍：

```python
pages = [
    ("style-page-point", {".num":"01", ".h":"招生官要的不是大事", ".body":"<p>……</p>"}),
    ("style-page-quote", {".big":"你反复在意的事<br>就是你真正在意的事"}),
    # …
]
for i,(style,fields) in enumerate(pages, start=2):
    pg.evaluate(f"document.body.className='{style}'")
    for sel,html in fields.items():
        pg.evaluate("([s,h])=>document.querySelector(s).innerHTML=h", [sel,html])
    pg.wait_for_timeout(300)
    pg.screenshot(path=f"page-{i}.png")
```

出完整套后**逐张看一遍**，重点查三件事：页码对不对、有没有哪页文字溢出、相邻两页的信息量是不是差太多（有的页满有的页空，一划就露怯）。

## AI 生图（氛围类封面）

情感、生活、旅行类的封面需要真实氛围感，模板做不出来。这时候输出一段 prompt 让用户去即梦 / Midjourney / 豆包生成。

**关键原则：不要让 AI 画中文字。** 中文字形复杂，AI 生成的中文几乎必定是错的。正确流程是：

1. AI 生成**纯画面**（留出放字的空白区域）
2. 把图存下来，在 `covers.html` 的 `style-photocard` 里把 `--photo` 换成这张图
3. 文字用模板叠上去

### Prompt 模板

```
[主体场景], [情绪/氛围词], [光线], [构图与留白], [色调], no text, no words, no letters, no watermark --ar 3:4
```

按类型的写法：

**情感 / 心理**
> 一个女生侧身坐在窗边，只拍到肩膀和窗外的光，室内昏暗，午后逆光，画面上方留大片空白，低饱和暖灰色调，胶片颗粒感，no text, no words --ar 3:4

**生活 / 日常**
> 木质书桌一角，一杯冒热气的咖啡和翻开的笔记本，自然侧光，俯拍，构图偏下留出上方空间，奶油色调，柔和阴影，no text, no words --ar 3:4

**旅行 / 探店**
> 老城区街道，梧桐树影落在墙上，行人虚化，黄昏斜射光，中景，画面下方留空，暖调胶片，no text, no words --ar 3:4

写 prompt 时注意：

- **必须写留白位置**（"上方留空"/"下方留空"），否则主体占满画面，字没地方放
- **必须带 `no text, no words`**，否则 AI 会自己加乱码文字
- 情绪词比物体词更重要 —— "孤独但平静"比"一个人"能给出更准的画面
- 不要写具体人脸特写，AI 人脸容易出问题，侧影、背影、局部更安全
