# 小红书个人 IP 风格母型

这份风格库解决两个问题：用户不必先交 3–5 段私人聊天才能拥有稳定风格；输入比较空泛时，也能先用明确的表达结构起稿。它只决定“怎么说”，不能替用户编造“发生过什么”。

## 使用方式

1. 先确定行业 / 身份与目标受众。
2. 只展示最相关的 4–6 张风格卡，不把整份列表扔给用户。
3. 让用户选 **1 个主风格 + 0–1 个辅助风格 + 1 个绝不要的风格**。
4. 针对同一主题给 3 段 80–120 字的校准样稿，让用户选最像自己的版本。
5. 把选择写成可执行的“风格 DNA”。不要要求用户模仿某位具体博主，也不要复制公开账号的原句。

完整笔记还要在动笔前单独选本篇表达方式（干货拆解、真实故事、观点表达、复盘日记或清单 / 测评）及交付格式；它们服务当篇，不写入长期风格 DNA。详见 `references/output-delivery.md`。

用户说“你帮我选”时，根据行业、身份和受众直接推荐一个组合，标成“暂定”；不让选择题阻塞创作。

## 十二种风格母型

### A01 · 冷静拆解者

- **适合**：心理科普、法律、财务、科技、职场、教育、专业服务。
- **关系感**：可信赖的解释者，不居高临下。
- **开头**：先给判断或拆掉一个误区，再解释原因。
- **节奏**：短句 + 清晰分层；少 emoji，少煽情。
- **证据**：定义、条件、过程、边界、真实案例中的可公开部分。
- **标志动作**：把复杂问题拆成 2–4 个判断点；主动说清“什么情况下不适用”。
- **避免**：万能结论、堆术语、假装权威、把相关性写成因果。
- **示例方向**：不是告诉读者“应该怎么做”，而是先说明“你现在卡在哪一种情况”。

### A02 · 犀利前辈

- **适合**：职场、商业、学生成长、健身、创业、行业经验。
- **关系感**：踩过坑的前辈，直接但不羞辱人。
- **开头**：点出一个常见但代价很高的错误。
- **节奏**：断句利落，判断明确，少铺垫。
- **证据**：亲历代价、复盘、前后变化、具体选择。
- **标志动作**：先说“不建议什么”，再给替代动作。
- **避免**：爹味、训话、制造焦虑、把个人经验包装成唯一答案。
- **示例方向**：把“你不够努力”改成“你把力气花在了不会被看见的地方”。

### A03 · 反常识辩手

- **适合**：情感观点、职场、商业、教育、消费观、个人成长。
- **关系感**：有立场的讨论者，不靠骂人赢。
- **开头**：提出与主流不同但可以论证的判断。
- **节奏**：观点—证据—边界—行动，避免连续对仗金句。
- **证据**：反例、条件差异、行为后果、亲身观察。
- **标志动作**：替读者区分“听起来正确”和“实际有用”。
- **避免**：性别对立、挑衅式标题、为了反对而反对、没有事实的绝对判断。
- **示例方向**：观点必须落到一个可验证场景，不发空泛“人间清醒”。

### A04 · 真实测评员

- **适合**：美妆、穿搭、科技、健身、家居、食品、课程和工具。
- **关系感**：替读者先试一次的人。
- **开头**：先交代使用条件与最意外的结果。
- **节奏**：过程记录 + 优缺点 + 适用人群，信息密度高。
- **证据**：使用时长、环境、肤质 / 设备 / 预算、前后差异、失败点。
- **标志动作**：明确“适合谁 / 不适合谁”，保留缺点。
- **避免**：无依据打分、踩一捧一、伪造数据、把感受写成功效保证。
- **示例方向**：不是“好用到哭”，而是“连续用了多久、在哪一步省了什么”。

### A05 · 买手筛选官

- **适合**：美妆、服饰、母婴、家居、食品、生活方式。
- **关系感**：有标准的选择助手，不是商品播报员。
- **开头**：先说筛选标准或这次替谁选。
- **节奏**：需求—标准—候选—取舍，结论先行。
- **证据**：预算、材质、场景、维护成本、替代品。
- **标志动作**：告诉读者“为什么没选另外几个”。
- **避免**：全是优点、假装自购、隐瞒合作、用身份压迫消费。
- **示例方向**：把“闭眼入”改成“符合这三个条件再买”。

### A06 · 在地侦察员

- **适合**：旅行、探店、本地生活、校园、城市观察、美食。
- **关系感**：住在这里、替你走过一遍的人。
- **开头**：从时间、路线、排队、价格或一个现场细节切入。
- **节奏**：沿真实动线写，像带读者一起走。
- **证据**：日期、位置、交通、等候时间、人均、现场限制。
- **标志动作**：给“什么时候去 / 从哪边进 / 哪类人别去”的具体判断。
- **避免**：过期信息、假装本地人、只堆形容词、标题与体验不符。
- **示例方向**：让读者看完能照着完成一次行动。

### A07 · 闺蜜口述者

- **适合**：情感、女性成长、日常、穿搭、美妆、生活选择。
- **关系感**：私下聊天般亲近，但不假装认识读者。
- **开头**：一句真实反应、对话或当时脑中的念头。
- **节奏**：口语短段、少量停顿、自嘲或轻吐槽。
- **证据**：具体对话、身体感受、犹豫和不体面的细节。
- **标志动作**：允许矛盾和没想明白，不强行升华。
- **避免**：“姐妹们听我说”、假亲密、编造故事、情感操控。
- **示例方向**：像把一件刚发生的事讲给朋友，而不是写情感语录。

### A08 · 温柔陪伴者

- **适合**：情感、心理健康、母婴、慢病陪伴、学生压力、个人成长。
- **关系感**：理解处境的人，不抢着给答案。
- **开头**：先准确描述读者正在经历的一个瞬间。
- **节奏**：留白多、语气克制、建议少而具体。
- **证据**：可识别的生活场景、感受变化、可执行的小动作。
- **标志动作**：先承接感受，再给一个低门槛选择。
- **避免**：空泛疗愈、心理诊断、承诺治愈、把痛苦浪漫化。
- **示例方向**：不说“你要爱自己”，而是给今天能完成的一小步。

### A09 · 场景故事家

- **适合**：情感、母婴、学生、旅行、职业经历、品牌主理人。
- **关系感**：把读者带进现场的叙述者。
- **开头**：时间 + 地点 + 一个动作或一句话。
- **节奏**：场景—变化—选择—余味；少解释，多让细节说话。
- **证据**：人物动作、环境、原话、时间顺序。
- **标志动作**：结尾回到开头的物件或动作，不硬总结道理。
- **避免**：虚构戏剧冲突、替别人编对白、强行反转、编“真实故事”。
- **示例方向**：只写用户确认发生过的事；缺口用明确占位符。

### A10 · 成长日记员

- **适合**：学生、健身、创业、转行、技能学习、家居改造、长期项目。
- **关系感**：和读者一起走的人，不是假装已经成功的导师。
- **开头**：第几天 / 第几次 / 当前进度 + 一个真实卡点。
- **节奏**：目标—尝试—失败—调整—下一步。
- **证据**：阶段记录、时间投入、过程截图、可核实的小结果。
- **标志动作**：保留失败与反复，形成固定连载栏目。
- **避免**：伪造逆袭、只晒结果、虚构成绩、把一次变化归功于单一方法。
- **示例方向**：学生博主优先写课程、社团、宿舍、图书馆、实习等真实场景。

### A11 · 高能教练

- **适合**：健身、备考、效率、执行力、技能训练、挑战计划。
- **关系感**：一起行动的教练，不是喊口号的监督者。
- **开头**：直接给今天要完成的动作或挑战。
- **节奏**：动词开头、步骤短、反馈明确。
- **证据**：次数、时长、完成标准、复盘节点。
- **标志动作**：把大目标拆成 10–30 分钟能完成的任务。
- **避免**：羞辱、意志力崇拜、健康风险、夸张结果承诺。
- **示例方向**：每条内容都要让读者知道“下一步具体做什么”。

### A12 · 审美策展人

- **适合**：穿搭、美妆、家居、摄影、旅行、读书、艺术、生活方式。
- **关系感**：有稳定取舍标准的人，不只是“好看分享”。
- **开头**：一个画面、材质、颜色或反复出现的审美判断。
- **节奏**：文字少而准，感官细节强，避免形容词堆砌。
- **证据**：材质、光线、比例、搭配逻辑、空间或使用场景。
- **标志动作**：持续使用一组审美关键词和取舍标准。
- **避免**：空洞氛围感、伪文艺、所有东西都说高级、忽略实用限制。
- **示例方向**：写清“为什么留下它”，而不只是“它很美”。

## 行业 / 身份推荐

风格母型和行业是两层。下面只是起始推荐，用户可以跨界组合。

| 行业 / 身份 | 优先推荐 | 需要的真实锚点 | 主要边界 |
|---|---|---|---|
| 美妆穿搭 | A04 + A05 / A12 | 肤质、体型、预算、使用环境 | 不伪造功效，不制造身体羞耻 |
| 母婴教育 | A08 + A09 / A01 | 孩子阶段、家庭场景、实际反应 | 不替孩子编话，不做医疗承诺 |
| 情感博主 | A07 + A09 / A08 / A03 | 原话、关系节点、自己的选择 | 不虚构故事，不诊断，不煽动性别对立 |
| 心理健康 | A01 + A08 / A09 | 触发场景、感受、已尝试行动 | 不下诊断，不替代专业帮助 |
| 学生博主 | A10 + A02 / A06 / A11 | 年级、课程、校园场景、真实成绩或预算 | 不伪造学校、排名、录取、实习经历 |
| 职场商业 | A02 + A01 / A03 | 岗位、阶段、决策、实际代价 | 不编业绩，不泄露公司或客户隐私 |
| 法律财务 | A01 + A02 / A03 | 适用地区、身份、条件、资料来源 | 必须提示边界，不承诺结果 |
| 健身运动 | A11 + A10 / A04 | 基础水平、周期、训练记录 | 不承诺体重变化，不给危险动作 |
| 家居生活 | A12 + A10 / A04 | 户型、尺寸、预算、维护成本 | 不隐瞒使用代价，不伪造改造结果 |
| 科技数码 | A04 + A01 / A02 | 设备、版本、使用周期、测试条件 | 不把单次体验写成普遍结论 |
| 旅行探店 | A06 + A09 / A12 | 日期、路线、人均、现场限制 | 信息要标时间，不假装本地人 |

### 情感博主专用提醒

- 空泛的情感语录、两性大道理和个人成长鸡汤不能算个人风格。
- 一条内容至少要有一个真实关系节点：一句原话、一个动作、一次决定或一个具体后果。
- “人间清醒”只能作为表达温度，不能替代证据；观点必须写清适用条件。

### 学生博主专用提醒

- “学习干货”和“校园日常”同质化高，优先把个人爱好、专业、校园资源或长期项目组合进定位。
- 可用场景：课堂、实验室、图书馆、社团、宿舍、食堂、考试周、实习、通勤、学生党预算。
- 成绩、学校、保研 / 留学 / 录取和实习结果都属于高风险真实性字段，缺失时只能询问或使用占位符。

## 输入空泛时：具体化补强

风格可以补表达，不能补事实。用户只说“写一篇关于成长的笔记”时，不要直接产出一篇正确但空洞的文章。先给一个内容假设，再最多问 3 个高价值问题：

1. **现场**：这件事发生在什么时候 / 哪里？给用户与行业相关的 3 个选项。
2. **变化**：当时最难、最意外或最后改变了什么？
3. **证据**：有没有一句原话、一个数字、一次失败或一个真实选择？

问题要具体到容易回答。例如学生博主不要问“你的经历是什么”，改问：

> 这条更接近哪种真实场景：①考试周在图书馆熬不住 ②社团和课程撞车 ③第一次实习发现自己不会做事？

用户说“先给我一个版本”时可以继续，但必须：

- 用 `[请替换：真实场景]`、`[请填写：实际数字]` 标出事实缺口。
- 不把行业常见故事写成用户亲历。
- 文案交付后列出最值得补回的 1–2 个细节。

## 风格 DNA 档案

```markdown
# 声音档案
更新于：<日期>（第 N 次）

## 风格 DNA
- 行业 / 身份：
- 目标读者：
- 主风格：<A01-A12>
- 辅助风格：<可空>
- 明确不要：<一个母型或具体表达>
- 与读者的关系：
- 情绪温度：低 / 中 / 高
- 叙事视角：第一人称 / 第二人称 / 混合
- 证据偏好：场景 / 数字 / 过程 / 对话 / 专业来源
- 每篇标志动作：<最多 2 个>

## 微习惯
- 问句：<是否使用、什么语境>
- 语气词：<呢 / 呀 / 吧等；频率与位置>
- 标点：<破折号 / 省略号 / 感叹号等>
- emoji / 颜文字：<允许的池、频率和位置>
- 开头 / 结尾：<可选的固定习惯>

## 稳定规则
- <在至少 3 个不同主题中出现，或由用户明确确认>

## 已确认偏好
- <用户选择、明确反馈或确认过的改稿规则>

## 待观察
- <模型推断或只出现过一次的信号，不直接当硬规则>

## 禁用词与禁用句式
- ...

## 校准样稿
- <用户选中的 80–120 字样稿>
```

每篇文案应用主风格，辅助风格最多占 30%。不要把十二种技巧都塞进一篇；稳定出现的两个标志动作，比堆满风格更容易形成个人 IP。

## 持续学习信号

| 信号 | 默认置信度 | 怎么处理 |
|---|---|---|
| 用户主动选择主 / 辅助风格 | 已确认 | 可直接写入已授权保存的档案 |
| 用户从标题或样稿中选一个 | 已确认于当前语境 | 记录选择原因；跨主题重复后升为稳定 |
| 用户明确说“更短 / 别说教 / 不要 emoji” | 已确认 | 转成可执行规则 |
| 用户发回改稿 | 待确认 | 对比差异，问是否固化 |
| 普通聊天中的语言习惯 | 待观察 | 不能未经确认当成公开表达规则 |
| 发布数据表现 | 内容信号 | 用于判断结构与选题，不直接当声音偏好 |

只有用户已经同意保存长期档案时才持续写入。一次输出结束后，即使没有生成图片，也要处理本轮出现的文字偏好信号。

## 研究依据

风格母型是对公开趋势、行业案例和创作者研究的抽象，不代表平台官方分类，也不对应某个具体博主：

- [小红书《2024 创作者趋势报告》摘要](https://www.fxbaogao.com/detail/4483643)：UGC、真实自我和多元圈层表达。
- [小红书《2025 社会责任报告》](https://whlyj.sh.gov.cn/cmsres/9e/9e992bffa7294a87ab39bbd394c7298d/68422e9020c521e1ac3bbb2b06ceadb9.pdf)：鼓励有用、有审美、有温度的内容，治理虚假与低质内容。
- [小红书蒲公英帮助中心](https://pgy.xiaohongshu.com/help/detail?id=6495c527d1eedeeb48fb18b1f875650e&userType=4)：情感鸡汤等空泛低信息内容、虚构故事和不真实学习成果属于重点风险。
- [《2025 母婴社交媒体内容洞察》](https://pdf.dfcfw.com/pdf/H3_AP202511101778796734_1.pdf%3F1762804663000.pdf)：生活场景、人物特色、情绪价值和专业内容共同形成差异化。
- [《从“种草”到“共情”》](https://www.xmtyj.org.cn/zh/article/doi/10.16604/j.cnki.issn2096-0360.2025.18.004/)：不完美人设、层次化自我表露、陪伴感和固定栏目有助于关系建立。
- [《70% 新闻传播专业学生做起自媒体》](https://news.cyol.com/gb/articles/2025-02/24/content_LgAgOlSG7P.html)：学生内容集中在日常与学习经验，结合专业和个人爱好更利于差异化。
