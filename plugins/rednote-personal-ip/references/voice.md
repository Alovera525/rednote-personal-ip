# 声音档案：让笔记听起来真的是本人写的

个人 IP 的产品就是声音本身。选题会撞、封面会像、方法论人人都查得到，唯一无法复制的是"这话只有她会这么说"。

所以"语气：像朋友"这种颗粒度是不够用的 —— 两个都写"像朋友"的账号，产出会一模一样。这个文件讲怎么把它做细。

---

## 为什么单独存一个档案

- **IP 档案**管"我是谁、写给谁"——战略，定了很少变
- **声音档案**管"我怎么说话"——执行，需要频繁微调

混在一起的后果是：每次想调语气都得重写整个档案，用几次就懒得改了，档案很快作废。分开存，改起来才没有心理负担。

---

## 一、先建立风格底座，不让用户凭空描述

直接问“你是什么风格”拿不到能用的东西。所有人的回答都是“真诚、接地气、有温度”——这些词无法执行，写出来的东西还是原样。

新用户先读 `references/style-archetypes.md`：根据行业 / 身份只展示 4–6 个相关母型，让他选 1 个主风格、0–1 个辅助风格和 1 个明确不要的风格。再用同一主题生成 3 段短样稿做校准。用户不想选时直接推荐一个暂定组合，不要卡住创作。

风格母型提供起点，真实反馈负责把它逐渐变成这个用户独有的声音。不要把母型当成永久模板，也不要模仿具体博主。

---

## 二、五类声音信号

3–5 段自然语料只是可选的校准方式，不再是建档前置条件。按下面的来源持续补全：

1. **风格选择**：用户选中的主 / 辅助母型、明确不要的风格。
2. **候选选择**：用户从标题、开头或校准样稿中选了哪一个，以及为什么。
3. **明确反馈**：“更短”“不要说教”“别用 emoji”等直接要求。
4. **原稿与改稿 diff**：最强的具体语境信号。
5. **自然语料（可选）**：微信长消息、朋友圈、群聊、语音转文字，或本人最满意的已发布笔记。

自然语料不足时也能建立“风格 DNA”，但从母型推导的内容只放“已确认偏好”或“待观察”，不能假装已经完全学会本人语言。

**要避开的做法**：只用简历、作业、工作汇报推断口语；把一条高数据笔记的选题特性误当成声音；从私人聊天自动推断公开表达规则。

---

## 三、提取什么：只记可观测特征

记"轻松幽默"没有任何用，下次也执行不了。要记成能对着检查的东西：

| 维度 | 怎么看 | 记成什么样 |
|---|---|---|
| 句长 | 平均多少字，有没有超过 35 字的句子 | 「平均 15-20 字，几乎不写长句」 |
| 标点 | 破折号 / 省略号 / 感叹号 / 问号的频率 | 「爱用省略号收尾，几乎不用感叹号」 |
| 人称 | 我 / 你 / 咱 / 大家 的比例 | 「第一人称为主，偶尔'你'，从不说'大家'」 |
| emoji / 颜文字 | 用不用、固定哪几个、放哪 | 「只用 🌱✨，句尾，一篇最多 2 个」 |
| 语气词 | 呢 / 呀 / 吧等是否自然出现、放在哪 | 「偶尔用‘呢’收问题，不在每段句尾加」 |
| 口头禅 | 反复出现的词组 | 「‘说实话’‘其实’‘反正’」 |
| 段落 | 如何按意思分段、单句段落的用途 | 「一段只讲一个完整意思；只有转折才单独成段」 |
| 修辞 | 自嘲 / 反问 / 比喻 各爱不爱用 | 「爱自嘲，不爱反问」 |
| 结尾 | 习惯怎么收尾 | 「一句轻的话带过，不做总结」 |
| **禁用** | **她绝对不会说的话** | 「赋能、闭环、家人们、不得不说、划重点」 |

还要记录风格 DNA：主 / 辅助母型、与读者的关系、情绪温度、叙事视角、证据偏好，以及每篇稳定出现的最多两个“标志动作”。微习惯也是声音档案的一部分，但本篇的“干货拆解 / 真实故事 / 观点表达 / 复盘日记 / 清单测评”属于一次性结构选择，不要误存成长期声音。完整字段见 `references/style-archetypes.md`。

**禁用清单是所有项里最有用的一项。** 正面描述再准，也拦不住模型滑回 AI 腔；一张负面清单可以直接拦住。

用户想不出禁用词时，反过来问："下面这几句里，哪句最不像你说的？"——给三四个候选让他挑，比让他凭空想容易得多。

## 四、档案长什么样

```markdown
# 声音档案
更新于：2026-08-01（第 3 次）

## 风格 DNA
- 行业 / 身份：学生博主 · 设计专业
- 目标读者：刚开始做作品集的大一大二学生
- 主风格：A10 成长日记员
- 辅助风格：A12 审美策展人
- 明确不要：A11 高能教练；不要打鸡血
- 与读者的关系：一起练习的学姐
- 每篇标志动作：记录一个失败；写清一次取舍

## 稳定规则（跨主题重复或用户明确确认）
- 平均句长 15-20 字，超过 35 字就拆
- 段落按完整意思分开；钩子或转折才单独成段
- emoji 只用 🌱✨，放句尾，一篇最多 2 个
- 问句偶尔用“呢”收尾，不连着使用
- 不下绝对结论，用自己的时间尺度说话

## 已确认偏好
- 三次标题选择都偏向具体场景，不选“逆袭”“必看”类钩子

## 禁用词
赋能 / 闭环 / 家人们 / 不得不说 / 划重点 / 干货满满 / 建议收藏

## 例句对照
| ❌ AI 腔 | ✅ 她会说 |
|---|---|
| 这三个方法可以有效帮助你缓解焦虑 | 这三个我自己试过，最管用的是第二个 |
| 希望这篇文章对你有帮助 | 写完感觉轻松多了，希望你也是 |

## 待观察（样本还不够，先别当规则用）
- 似乎不爱用反问句（只见过 2 次，再看看）
```

三个区块的划分很重要：

- **稳定规则** —— 在至少三个不同主题里重复出现，或用户明确要求长期遵守
- **已确认偏好** —— 用户明确选择或反馈过，但可能仍有语境限制
- **待观察** —— 样本不足的，先记着不执行。一次偶然被固化成风格，比没有档案更糟
- **例句对照** —— 比规则管用。规则容易被理解成别的意思，例句不会

## 五、怎么持续学习：图片不是前置条件

这是整套机制里最重要的一环。

用户没有生成图片，文字风格也必须继续学习。风格选择、标题选择、明确反馈和改稿都能成为信号；图片只影响视觉，不影响声音档案。

**用户每次修改产出，那个 diff 仍然是质量最高的偏好信号**——比任何自述都准，因为那是他在具体语境下的真实选择，不是想象出来的偏好。

所以收到用户改过的版本时，不要只是接受，要**对比 → 反推规则 → 追加进档案**：

| 他改了什么 | 反推出的规则 |
|---|---|
| "这真的很有效" → "我用了两周才有感觉" | 不下绝对结论，用自己的时间尺度说话 |
| 删掉了所有"首先/其次/最后" | 不用书面连接词，靠空行分隔 |
| "大家好呀，今天想聊聊…" → 直接进正文 | 不寒暄，第一句就是内容 |
| 把三个 emoji 删到只剩一个 | emoji 克制，一篇最多两个 |
| "你是不是也这样" → "你也会这样想吗？" | 偏好温和问句；当前仅用于相似语境 |
| "你要记住" → "这个我后来才慢慢明白呢" | 偏好第一人称经验和句尾“呢”，先确认是否长期使用 |

处理规则：

- 已授权保存档案时，用户主动选择的风格和明确要求可以写进“已确认偏好”。
- 从候选选择中推断的原因，先保留当前语境；跨不同主题重复后再升为稳定规则。
- 从改稿推断的规则，追加前问：**“这条要不要固化下来？”**；普通聊天只记“待观察”，不能未经确认进入公开文案。
- 发布数据只说明选题或结构表现，不直接证明用户喜欢某种语气。

用户可能只是这一条不想那么说，不代表以后都不。不区分信号来源就往里加，档案会越来越紧，最后把人框死。

### 微习惯的使用上限

微习惯的目的是让人认得出，不是把每个口头禅都塞进去。每篇只选择 1–2 条稳定或已确认的微习惯；问句、句尾“呢 / 呀 / 吧”、省略号、emoji / 颜文字和小自嘲都算。一次偶然的聊天用语、只出现一次的 emoji，或只在一个伤感主题里出现的句式，都只能待观察。

## 六、两个过拟合风险

**把母型当成本人。** 风格卡只是第一版假设。没有经过选择、样稿校准或真实反馈的细节都放“待观察”。

**把选题特性当成风格。** 一条讲难过的事写得沉，不代表这个人的风格是沉重。判断方法很简单：**这个特征在不同主题的语料里都出现吗？** 只在一个主题里出现的，是内容属性，不是风格。

---

## 七、和 IP 档案冲突时怎么办

声音档案管"怎么说"，IP 档案管"说什么、对谁说"。冲突时**以 IP 档案的目标人群为准**。

比如用户私下爱用网络烂梗，但账号的目标人群是家长——这时候要收着用。声音档案是他的自然语言，不是不加筛选地照搬到公开表达里。

同理，专业专家类账号即使本人说话很随意，涉及专业结论的段落也要回到克制的表达，这是可信度问题，不是风格问题。
