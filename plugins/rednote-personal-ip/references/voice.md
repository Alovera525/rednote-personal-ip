# 声音档案：让笔记听起来真的是本人写的

个人 IP 的产品就是声音本身。选题会撞、封面会像、方法论人人都查得到，唯一无法复制的是"这话只有她会这么说"。

所以"语气：像朋友"这种颗粒度是不够用的 —— 两个都写"像朋友"的账号，产出会一模一样。这个文件讲怎么把它做细。

---

## 为什么单独存一个档案

- **IP 档案**管"我是谁、写给谁"——战略，定了很少变
- **声音档案**管"我怎么说话"——执行，需要频繁微调

混在一起的后果是：每次想调语气都得重写整个档案，用几次就懒得改了，档案很快作废。分开存，改起来才没有心理负担。

---

## 一、别问用户"你是什么风格"

问了也拿不到能用的东西。所有人的回答都是"真诚、接地气、有温度"——这些词无法执行，写出来的东西还是原样。

**要语料，从真实文本里提取。**

---

## 二、要什么样的语料

3-5 段，最少 3 段。优先级从高到低：

1. **微信里发给朋友的长消息**——最真实，几乎没有自我审查
2. **朋友圈、群里的吐槽**
3. **语音转文字**——口语特征最完整
4. 已发过的笔记里，数据最好的 2 条 + 她自己最满意的 1 条

**要避开的语料**：已发表的文章、简历、作业、工作汇报。这些都被自我审查成书面腔了，照着学只会得到一个更工整的 AI。

跟用户要的时候说清楚"越随意越好，不要挑写得好的"——用户天然会想交作业，得主动拦住。

---

## 三、提取什么：只记可观测特征

记"轻松幽默"没有任何用，下次也执行不了。要记成能对着检查的东西：

| 维度 | 怎么看 | 记成什么样 |
|---|---|---|
| 句长 | 平均多少字，有没有超过 35 字的句子 | 「平均 15-20 字，几乎不写长句」 |
| 标点 | 破折号 / 省略号 / 感叹号 / 问号的频率 | 「爱用省略号收尾，几乎不用感叹号」 |
| 人称 | 我 / 你 / 咱 / 大家 的比例 | 「第一人称为主，偶尔'你'，从不说'大家'」 |
| emoji | 用不用、固定哪几个、放哪 | 「只用 🌱✨，句尾，一段最多一个」 |
| 口头禅 | 反复出现的词组 | 「'说实话''其实''反正'」 |
| 段落 | 几句一段 | 「1-2 句一段，空行多」 |
| 修辞 | 自嘲 / 反问 / 比喻 各爱不爱用 | 「爱自嘲，不爱反问」 |
| 结尾 | 习惯怎么收尾 | 「一句轻的话带过，不做总结」 |
| **禁用** | **她绝对不会说的话** | 「赋能、闭环、家人们、不得不说、划重点」 |

**禁用清单是所有项里最有用的一项。** 正面描述再准，也拦不住模型滑回 AI 腔；一张负面清单可以直接拦住。

用户想不出禁用词时，反过来问："下面这几句里，哪句最不像你说的？"——给三四个候选让他挑，比让他凭空想容易得多。

## 四、档案长什么样

```markdown
# 声音档案
更新于：2026-08-01（第 3 次）

## 硬规则（每条都要遵守）
- 平均句长 15-20 字，超过 35 字就拆
- 段落 1-2 句，空行多
- emoji 只用 🌱✨，放句尾，一段最多一个
- 不下绝对结论，用自己的时间尺度说话

## 禁用词
赋能 / 闭环 / 家人们 / 不得不说 / 划重点 / 干货满满 / 建议收藏

## 例句对照
| ❌ AI 腔 | ✅ 她会说 |
|---|---|
| 这三个方法可以有效帮助你缓解焦虑 | 这三个我自己试过，最管用的是第二个 |
| 希望这篇文章对你有帮助 | 写完感觉轻松多了，希望你也是 |

## 待观察（样本还不够，先别当规则用）
- 似乎不爱用反问句（只见过 2 次，再看看）
```

三个区块的划分很重要：

- **硬规则** —— 确定的，每次执行
- **待观察** —— 样本不足的，先记着不执行。一次偶然被固化成风格，比没有档案更糟
- **例句对照** —— 比规则管用。规则容易被理解成别的意思，例句不会

## 五、怎么"学习优化"：改稿 diff 是最好的信号

这是整套机制里最重要的一环。

**用户每次修改产出，那个 diff 就是质量最高的偏好信号**——比任何自述都准，因为那是他在具体语境下的真实选择，不是想象出来的偏好。

所以收到用户改过的版本时，不要只是接受，要**对比 → 反推规则 → 追加进档案**：

| 他改了什么 | 反推出的规则 |
|---|---|
| "这真的很有效" → "我用了两周才有感觉" | 不下绝对结论，用自己的时间尺度说话 |
| 删掉了所有"首先/其次/最后" | 不用书面连接词，靠空行分隔 |
| "大家好呀，今天想聊聊…" → 直接进正文 | 不寒暄，第一句就是内容 |
| 把三个 emoji 删到只剩一个 | emoji 克制，一段最多一个 |

追加时问一句：**"这条要不要固化下来？"**

因为用户可能只是这一条不想那么说，不代表以后都不。不问就往里加，档案会越来越紧，最后把人框死。

---

## 六、两个过拟合风险

**语料不足就总结规则。** 少于 3 段时只做参考，所有结论都放"待观察"。

**把选题特性当成风格。** 一条讲难过的事写得沉，不代表这个人的风格是沉重。判断方法很简单：**这个特征在不同主题的语料里都出现吗？** 只在一个主题里出现的，是内容属性，不是风格。

---

## 七、和 IP 档案冲突时怎么办

声音档案管"怎么说"，IP 档案管"说什么、对谁说"。冲突时**以 IP 档案的目标人群为准**。

比如用户私下爱用网络烂梗，但账号的目标人群是家长——这时候要收着用。声音档案是他的自然语言，不是不加筛选地照搬到公开表达里。

同理，专业专家类账号即使本人说话很随意，涉及专业结论的段落也要回到克制的表达，这是可信度问题，不是风格问题。
