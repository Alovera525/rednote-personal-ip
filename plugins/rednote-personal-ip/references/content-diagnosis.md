# 内容成长诊断

只在交付“标题 + 正文”或“完整笔记”时使用。诊断对象是**当前已确认材料与当前稿**，不是用户本人，也不是流量预测。没有被用户确认的经历、数据、对话、结果或偏好不得作为评分依据。

## 输出格式

标题、正文、显式三层 Hashtag 与置顶评论之后，固定追加：

```text
【内容成长诊断】<总分> / 35｜<当前阶段>

1. 真实锚点｜<n> / 5
   已有：<只写确认过的场景、过程、原话、数据或方法>
   可补：<一个最有价值的具体缺口>
…

【下一版怎么更好】
1. <优先补充的材料 / 选择 / 边界>
2. <优先调整的结构 / 叙事方向>
3. <若需要，再补的个人风格信息>
```

每项只写 1 个“已有”和 1 个“可补”，总建议最多 3 条。指出缺口要可执行，不能写“更有深度”“更真诚”这类空话。

## 七个维度

每项 0–5 分；按已有证据给分，不为凑分猜测。

| 维度 | 看什么 | 低分时优先补什么 |
|---|---|---|
| 真实锚点 | 场景、动作、原话、过程、数据、方法或可核对边界是否足够具体 | 一个发生在何时何地的瞬间、一次实际选择、一个步骤或一条原话 |
| 个人位置 | 作者为什么有资格、又以什么有限视角说这件事 | 身份、所处阶段、亲历范围、与议题的真实关系 |
| 冲突与变化 | 是否有问题、代价、误判、取舍或前后变化 | 当时最难的卡点、放弃了什么、后来怎么调整 |
| 内容价值 | 读者能带走判断、方法、参照或情绪理解，而不只是结论 | 一个判断标准、可做动作、反例、适用 / 不适用边界 |
| 结构与节奏 | 主线是否清楚，段落是否有推进而不是拼贴 | 先明确核心结论；删掉离题段；补一个转折、因果或收束 |
| 人感与网感 | 是否有自然口语、具体观察、恰当节奏与平台可读性，且不油腻套话 | 一处真实观察、自然反应或读者可回应的问题；删 AI 套话与硬凹金句 |
| 个人风格辨识度 | 当前稿是否能看出“这是这个人会写的话” | 已确认口气、稳定微习惯、独特视角、固定栏目或个人经历；不靠堆 emoji / 口头禅 |

### 个人风格辨识度的判定

- **0–1 分**：没有声音档案或用户样本，当前稿换任何账号也基本成立。写“尚未建立足够的个人风格证据”，不要说用户没有风格。
- **2 分**：已选 IP 风格 / 口气，但只在少数句子里可见，缺少本人材料支撑。
- **3 分**：两个风格落点实际出现，且有一处来自用户的视角、经历或已确认习惯。
- **4 分**：口气、视角、素材和结构相互一致，读者能分辨出账号的内容立场。
- **5 分**：在不重复口头禅的前提下，形成稳定的个人判断、叙事方式或栏目记忆点。

对这一项的建议优先引导用户提供：1–3 篇自己的旧笔记、3 句真实常用表达、一个反复出现的生活 / 工作场景，或“我特别在意 / 反感什么”的具体判断。不得把别人的爆帖、口头禅或经历当作用户的风格。

## 分数如何使用

| 总分 | 当前阶段 | 本轮处理 |
|---|---|---|
| 24–35 | 可发布 | 直接交付；只给 1 个可选提升点 |
| 18–23 | 可发布初稿 | 直接交付；指出 2 个最高杠杆的补充方向 |
| 12–17 | 结构已成立，材料偏薄 | 有确认锚点时交付保守初稿；给 3 个补充方向，不用空话填满 |
| 0–11 | 先补材料 | 不伪装成可发布完整笔记；交付选题 / 结构与 6 个供确认的具体锚点候选 |

评分不用于压低用户表达，也不以文笔华丽、表情多少、篇幅长短加分。情绪类内容可以得高分，但仍需有真实关系节点、动作、原话或变化；干货类内容可以朴素，但需有方法、例子、标准或边界。

## 按内容类型补强

先按本篇内容选择最相关的提示，不把所有问题一次抛给用户。

| 类型 | 优先检查 / 引导补充 |
|---|---|
| 品牌 / 项目 / 职场复盘 | 一个真实决定、限制条件、取舍、结果或仍未解决的问题 |
| 人物故事 / 关系记录 / PLOG | 身份、触发瞬间、具体动作或原话、内在拉扯、后续回声 |
| 情感 / 成长随笔 | 一个真实关系节点或生活场景，避免只用抽象感悟与名人引语 |
| 干货 / 建议 / 清单 | 方法、例子、判断标准、适用边界和一个反例 |
| 影评 / 书评 / 文化评论 | 可核对的作品线索、个人观看 / 阅读触发，以及它如何照见作者自己 |
| 产品 / 商单 / 软植入 | 使用场景、选择条件、已确认的功能 / 体验、适合谁；不虚构效果或合作关系 |

用户暂时给不出实例时，沿用主工作流给出 6 个“供确认的内容锚点候选”；候选必须是可选择或修改的完整情境，不能冒充用户经历。
